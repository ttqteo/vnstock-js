## Implementation tasks

### Task 1 — Indicators v2 (MACD, Bollinger, ATR)

**Why first:** Pure functions, no network, foundation cho AI context. Easy to test với golden values.

- [ ] Create `src/indicators/macd.ts`:
  - `function macd(values: number[], opts?: { fast?: number; slow?: number; signal?: number }): { line: number[], signal: number[], histogram: number[] }`
  - Default 12/26/9. Internal reuse `ema()` từ v1.0.
  - Edge: input < slow period → fill nulls.
- [ ] Create `src/indicators/bollinger.ts`:
  - `function bollinger(values: number[], opts?: { period?: number; stddev?: number }): { upper: number[], middle: number[], lower: number[], percentB: number[] }`
  - Default period=20, stddev=2. `percentB` = (value - lower) / (upper - lower).
- [ ] Create `src/indicators/atr.ts`:
  - `function atr(candles: { high: number; low: number; close: number }[], period: number = 14): number[]`
  - Wilder smoothing. TR = max(high-low, |high-prevClose|, |low-prevClose|).
- [ ] Update `src/indicators/index.ts` re-export 3 functions mới.
- [ ] Create `__tests__/indicators/macd.test.ts`, `bollinger.test.ts`, `atr.test.ts`:
  - Golden values vs ta-lib reference (10-20 candle dataset trong test file).
  - Edge: empty array, < period length, NaN handling.
  - Date preservation nếu input là `QuoteHistory[]`.

**Verify:** `npx jest __tests__/indicators` xanh. `npm run build` không error.

### Task 2 — AI context layer (`aiContext` + `toAIPrompt`)

**Why second:** Compose indicators v2 + v1. Pure logic, no extra network beyond fetch candles 1 lần.

- [ ] Create `src/core/stock/pivot.ts`:
  - `function detectPivots(candles, opts?: { window?: number; topN?: number }): { support: number[]; resistance: number[] }`
  - Swing high/low detection trong sliding window.
- [ ] Create `src/core/stock/ai-context.ts`:
  - `function classifyTrend(candles): { direction, strength, rationale }` — rules-based: EMA20 > EMA50 > EMA200 + slope.
  - `function classifyVolume(candles): { today, avg20, signal, zscore }` — z-score > 2 → above_average.
  - `function computePerformance(candles): { change1d, change7d, change30d, change90d }`.
  - `function snapshotIndicators(candles): { rsi14, macd, sma, ema, bollinger, atr14 }` — call indicators, pick last value.
  - `async function aiContext(adapter, symbol, opts?: { lookback?: number })`: fetch candles, compose tất cả → AIContext object.
  - `async function toAIPrompt(adapter, symbol, opts?: { lang?: string })`: gọi aiContext → format plain-text.
- [ ] Wire vào `src/core/stock/index.ts`: thêm `aiContext()` và `toAIPrompt()` methods cho Stock class.
- [ ] Create `__tests__/ai-context.test.ts`:
  - Synthetic candles (mock fetch) với pattern rõ (uptrend 200 candles) → expect trend=bullish.
  - Pivot detection: cooked data có swing → expect levels match.
  - toAIPrompt output format: contains "Trend:", "RSI", "Support:", "Resistance:".
  - Edge: lookback < 200 → graceful fallback (skip SMA200).

**Verify:** `npx jest __tests__/ai-context` xanh. Manual test với 1 ticker thật (VCB) — print output để eyeball.

## Risks / Open questions

- **Indicators golden values:** ta-lib python output có thể khác với formula text. Cần verify với ≥2 sources (pandas-ta, TradingView) trước commit test.
- **Trend classifier false signal:** rules đơn giản (EMA chain + slope) có thể mis-classify sideways market. Document "neutral" default safe, encourage user reasoning.
- **MCP startup time:** dynamic import `@modelcontextprotocol/sdk` measured trên Windows. Nếu > 1s → Claude timeout. Fallback: warm pre-init khi `vnstock` CLI startup.
- **Watchlist concurrent writes:** Node atomic rename đảm bảo nhưng nếu 2 process cùng write → last-wins (race). Document warning, user lo single-writer.
- **VCI rate limit khi compute aiContext 200 candles × N symbols:** session cache + chunked fetch. Issue [#10](https://github.com/ttqteo/vnstock-js/issues/10) (Cloudflare detect) song song nên triển khai trước v1.4 nếu thấy 1015 trong dev.
- **Time-to-first-quote regression:** MCP startup không được làm chậm CLI thông thường. Dynamic import giải quyết, nhưng cần đo benchmark.
