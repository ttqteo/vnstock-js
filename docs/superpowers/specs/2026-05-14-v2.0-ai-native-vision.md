# v2.0 — AI-Native Vietnam Stock Research SDK (North Star)

**Date:** 2026-05-14
**Status:** Vision / north star — phase-able từ v1.4 → v2.0
**Target releases:** v1.4.0 (Foundation) → v1.5.0 (Workflow) → v1.6.0 (Reasoning) → v2.0.0 (RAG)

## 1. Positioning

vnstock-js evolves từ "VN stock SDK wrapper" → **"AI-Native structured market intelligence infrastructure cho Vietnam"**.

**Core philosophy:** _Structured market intelligence for AI reasoning._

**Mission:** Cung cấp primitives để build AI stock copilots, technical analysis workflows, investment research systems, watchlists, market memory, intelligent screening — không chỉ là OHLCV fetcher.

**Audience expansion:**
- (Today) JS/TS dev cần fetch VN stock data
- (+) Developer xây AI investing copilot / agent / dashboard
- (+) Quant hobbyist VN cần technical analysis primitives
- (+) Researcher cần historical reasoning + analog engine

## 4. Phase plan (Option B — 3 minor + 1 major)

### Phase 1 — v1.4.0 **AI-Native Foundation** (next up)

**Spec:** `2026-04-14-v1.4.0-mcp-server-design.md` (revised, see updated version)

**Theme:** Launch MCP server + AI primitives cùng lúc. Position vnstock-js là "AI research toolkit cho VN stock", không chỉ data fetcher.

In scope:
- **MCP server** (`vnstock mcp` stdio subcommand) — 11 tools (8 basic + 3 AI primitives)
- **Indicators v2 expansion** — MACD, Bollinger Bands, ATR (bổ sung vào SMA/EMA/RSI v1)
- **AI context layer** — `stock.aiContext(symbol)` trả structured JSON (trend, indicators, S/R pivot, volume signal)
- **Prompt helpers** — `stock.toAIPrompt(symbol)` trả plain-text format cho non-MCP LLM
- **Easy-mode helpers** — `quickQuote`, `recentHistory`, `compareSymbols`, `topMovers`
- **Watchlist module** — persist `~/.vnstock-js/watchlist.json`

Out of scope (defer):
- Pattern detection sâu (Cup&Handle, Triangle algorithmic) → v1.5
- Alerts/events realtime → v1.5
- Portfolio P/L → v1.5
- Fundamentals → v1.5
- Historical analog → v1.6

### Phase 2 — v1.5.0 **Power Workflow**

**Theme:** Hoàn thiện trader/analyst workflow daily. Patterns + alerts + screening + fundamentals + CLI commands còn thiếu.

In scope:
- **Pattern detection** (rules-based):
  - Breakout (price > N-day high với volume spike)
  - Support/Resistance tự động (swing pivot points)
  - Trend direction (slope ema20/ema50)
  - Double top/bottom (light heuristic)
  - Volume anomaly (z-score > 2)
- **Event/alert system:**
  - `stock.on("breakout", callback)` EventEmitter
  - Subscriber per-symbol, evaluate trên mỗi tick realtime
  - Persist subscription `~/.vnstock-js/alerts.json` cho long-running daemon
- **Fundamentals module** (đã shape sẵn ở v1.3.3 REST):
  - `stock.financials(symbol).balanceSheet/incomeStatement/cashFlow/ratios`
  - P/E, P/B, ROE, ROA, EPS, dividend yield helpers
- **Screener** (composable filter, KHÔNG full DSL — YAGNI):
  - `screener.where({ pe: { lt: 15 }, roe: { gt: 0.15 } })`
  - Presets: `valueStocks()`, `growthStocks()`, `dividendStocks()`
- **Portfolio basic:** input positions → marketValue, totalCost, P/L %
- **CLI fill-in:** `gold`, `market`, `compare`, `watchlist`, `screener` subcommands
- **Config file** `~/.vnstock-js/config.json`
- **MCP extension:** thêm tools `find_patterns`, `screen_stocks`, `get_fundamentals`, `watchlist_*`, `portfolio_summary`

Out of scope:
- Cup&Handle, Triangle pattern algorithmic (complexity, false positive cao) → v1.6
- Analog engine → v1.6
- DSL screener (`rsi(14) < 30 and volume > sma(volume,20) * 2`) → defer / drop
- Custom indicator builder framework → drop (YAGNI)

### Phase 3 — v1.6.0 **Historical Reasoning**

**Theme:** "Wow-factor" release. Cho phép find historical setups tương tự current condition — competitive moat vs TradingView/competitors.

In scope:
- **Analog engine:**
  - `stock.similarSetups(symbol, options?)` — return historical dates với điều kiện indicator/pattern khớp
  - Fingerprint: vector các indicator snapshot (RSI, MACD signal, volume z-score, trend slope) cho mỗi candle
  - Similarity: cosine distance giữa current fingerprint và historical fingerprints
  - Output: top-N dates + outcome window (return 5d/30d/90d sau setup)
- **Pattern detection nâng cao:** Cup&Handle, Triangle (ascending/descending/symmetric), Flag, Wedge
- **Signal backtest light:**
  - `stock.backtest(symbol, signal, options?)` — apply signal function trên historical, return entry/exit/PnL stats
  - Đơn giản: long-only, fixed position size, no slippage/fees model
- **MCP extension:** `find_similar_setups`, `backtest_signal`

Out of scope:
- Multi-symbol portfolio backtest → out of scope SDK
- Optimization framework (param sweep) → out of scope
- Realtime signal stream → đã có ở v1.5 alerts
- ML-based pattern detection → defer / không nhất thiết

### Phase 4 — v2.0.0 **RAG Research Memory**

**Theme:** Breaking major. Build research memory layer: ingest news + earnings + investment theses, expose semantic search + retrieval-augmented generation pipeline.

In scope:
- **Ingestion pipeline:**
  - News (extend v1.3.3 `vnstock.news` với full-text indexing)
  - Earnings reports (PDF parsing từ HOSE/HNX disclosure URLs)
  - Investment theses (user-supplied, markdown)
  - Macro notes (user-supplied, markdown)
- **Vector store integration:**
  - Adapter pattern: `pgvector`, `Qdrant`, `Weaviate` providers
  - Default: in-memory (toy use), opt-in remote for production
  - Embedding via OpenAI/Cohere/local sentence-transformers (user choice)
- **Semantic search API:**
  - `research.search("Vietcombank Q3 earnings")` → ranked passages
  - `research.context(symbol, query)` → blended structured + retrieved context cho LLM
- **MCP tools:** `search_research`, `get_company_research_context`

**Breaking changes:**
- New required peer deps (vector store client tùy chọn)
- `vnstock.news` API expand: persist + indexing thay vì stateless fetch
- May require config schema migration

Out of scope:
- Research notebook UI — separate project, không phải SDK
- Auto-summarize via LLM (user lo, SDK chỉ provide context)
- Real-time stream RAG → defer

## 5. Explicit drops (đã cân nhắc, không làm)

| Idea | Lý do drop |
|---|---|
| Multi-source fallback (SSI/TCBS/FireAnt/CafeF) | VCI đủ dùng, maintain 4 adapters cost cao, 1 maintainer. Revisit nếu VCI block thật. |
| Research notebook UI | Separate project (web app), không phải SDK scope. SDK provide primitives, notebook là UI layer riêng. |
| Full DSL screener (`rsi(14) < 30 AND ...`) | YAGNI. Composable filter object đủ 95% use case. DSL = parser maintenance. |
| Custom indicator builder framework | Premature abstraction. User extends bằng cách compose existing indicators. |
| Multi-symbol portfolio backtest | Out of SDK scope — quá phức tạp (fees, slippage, position sizing). Defer indefinitely. |
| ML-based pattern detection | Rules-based đủ cho VN market hiện tại. ML maintenance + training data + reproducibility costly. |

## 7. Risks + mitigation

| Risk | Mitigation |
|---|---|
| Scope creep v1.4 (11 tool + 6 module mới quá lớn) | Strict in/out scope. Cup&Handle/Triangle/Analog **strictly defer**. Ship v1.4 trong 2-3 tuần dev. |
| Pattern detection false positive | Bắt đầu rules-based đơn giản (breakout, S/R), document confidence score. ML defer. |
| Analog engine compute scale | Precompute fingerprints offline, lưu trong package data (như `symbols.json`). Similarity search O(n) đủ với <100k candles. |
| VCI rate limit khi build features cần nhiều history | Local cache TTL aggressive, fixture-based tests (xem issue #9), background prefetch warming. |
| Vector store dep complexity | Adapter pattern, in-memory default, remote opt-in. User không bị force install pgvector/Qdrant. |
| MCP positioning chaos | Single doc explain "MCP = surface, SDK = core". Mỗi release update MCP tools cùng với SDK feature. |
