# v1.4.0 — AI-Native Foundation (MCP + Indicators v2 + AI Context)

**Date:** 2026-04-14 (revised 2026-05-14)
**Status:** Draft, pending user review
**Target release:** v1.4.0 — Phase 1 của north star [`v2.0-ai-native-vision.md`](2026-05-14-v2.0-ai-native-vision.md)

## 1. Overview

v1.4.0 launches vnstock-js là **"AI Research Toolkit cho VN stock"** — không chỉ data fetcher. Bundle 4 capability cùng release để có coherent launch story:

1. **MCP server** — distribution surface cho Claude Desktop / Cursor / VS Code
2. **Indicators v2** — MACD, Bollinger Bands, ATR (bổ sung vào SMA/EMA/RSI v1)
3. **AI primitives** — `stock.aiContext()`, `stock.toAIPrompt()` (structured + plain-text cho LLM)
4. **UX foundation** — Easy-mode helpers + Watchlist module

Reposition từ "MCP wrapper" (spec gốc) → "AI Foundation" vì:
- MCP một mình thiếu vũ khí — chỉ trả OHLCV thô, Claude phải tự reason
- Indicators v2 + AI context biến mỗi tool call thành "structured insight" thay vì raw data dump
- USP: VN-native market intelligence pre-computed, không phải VN-data passthrough

## 2. Scope

### In

**MCP server (distribution layer):**
- Subcommand `vnstock mcp` — stdio MCP server, dùng `@modelcontextprotocol/sdk`
- 11 tools (8 basic + 3 AI primitives — xem Section 5)
- Bilingual tool descriptions (Vi + En)
- Install guides cho Claude Desktop, Cursor, VS Code
- Submit MCP registry

**Indicators v2 (core capability):**
- `stock.indicators.macd(candles, opts?)` — fast/slow/signal periods configurable
- `stock.indicators.bollinger(candles, opts?)` — period + stddev configurable
- `stock.indicators.atr(candles, period?)` — Average True Range
- Existing SMA/EMA/RSI giữ nguyên API

**AI primitives:**
- `stock.aiContext(symbol, opts?)` — structured JSON: trend, indicators snapshot, S/R pivot, volume signal
- `stock.toAIPrompt(symbol, opts?)` — plain-text formatted cho non-MCP LLM (OpenAI, Gemini, local)
- Trend classifier rules-based (slope ema20/ema50, RSI band)
- S/R bằng pivot points (5-day window swing high/low)

**Easy-mode helpers** (top-level SDK):
- `vnstock.quickQuote("VCB")` — giá hiện tại + change %
- `vnstock.recentHistory("VCB", 30)` — N phiên gần nhất
- `vnstock.compareSymbols(["VCB", "TCB"])` — bảng giá + change %
- `vnstock.topMovers()` — gainers + losers cùng response

**Watchlist module:**
- `vnstock.watchlist.add/remove/list/quotes(name)/create/delete`
- Persist: Node `~/.vnstock-js/watchlist.json`. Browser: user lo (optional localStorage hook)

### Nguyên tắc

- **MCP = thin layer trên SDK** — không logic riêng. Mỗi feature SDK mới ↔ 1 MCP tool mới.
- **AI primitives compose existing** — `aiContext` = trend classifier + indicators snapshot + pivot calc. Không gọi extra API.
- **Lazy init** — `await init()` chỉ khi tool cần symbols/calendar. Quote tools skip → startup <500ms.
- **Session cache** quote (30s) + AI context (60s) — Claude hỏi cùng symbol nhiều lần.
- **Pure functions cho indicators** — tách `pipeline/transform` style, không phụ thuộc adapter.

## 6. Indicators v2 design

### MACD

```typescript
function macd(
  candles: QuoteHistory[],
  opts: { fast?: number; slow?: number; signal?: number } = {}
): { date: string; line: number; signal: number; histogram: number }[]
```

Default: 12/26/9 (industry standard). Reuse `ema()` từ v1.0 cho internal.

### Bollinger Bands

```typescript
function bollinger(
  candles: QuoteHistory[],
  opts: { period?: number; stddev?: number } = {}
): { date: string; upper: number; middle: number; lower: number; percentB: number }[]
```

Default: period=20, stddev=2. `percentB` = (close - lower) / (upper - lower) — 0..1+ range.

### ATR

```typescript
function atr(candles: QuoteHistory[], period: number = 14): { date: string; atr: number }[]
```

Wilder smoothing. True Range = max(high-low, |high-prev_close|, |low-prev_close|).

### Tests
- Edge cases: empty array, candles < period
- Known values: golden test với data có truth value pre-computed Python (ta-lib reference)
- Date preservation từ input

## 7. AI context layer design

### Module: `src/core/stock/ai-context.ts`

```typescript
export async function aiContext(
  symbol: string,
  opts: { lookback?: number } = {}
): Promise<AIContext> {
  const lookback = opts.lookback ?? 200;
  const candles = await fetchRecentCandles(symbol, lookback);

  return {
    symbol,
    asOf: candles[candles.length - 1].date,
    trend: classifyTrend(candles),
    indicators: snapshotIndicators(candles),
    levels: detectPivots(candles, { window: 5 }),
    volume: classifyVolume(candles),
    performance: computePerformance(candles),
  };
}
```

### Trend classifier (rules-based)

```typescript
function classifyTrend(candles): { direction, strength, rationale } {
  const closes = candles.map(c => c.close);
  const ema20 = lastValue(ema(closes, 20));
  const ema50 = lastValue(ema(closes, 50));
  const ema200 = lastValue(ema(closes, 200));
  const slope20 = computeSlope(ema(closes, 20).slice(-5));

  let direction: "bullish" | "bearish" | "neutral";
  if (ema20 > ema50 && ema50 > ema200 && slope20 > 0) direction = "bullish";
  else if (ema20 < ema50 && ema50 < ema200 && slope20 < 0) direction = "bearish";
  else direction = "neutral";

  const strength = computeStrength(ema20, ema50, ema200, slope20); // 0..1
  return { direction, strength, rationale: buildRationale(direction, ...) };
}
```

### Volume signal

```typescript
function classifyVolume(candles): { today, avg20, signal, zscore } {
  const volumes = candles.map(c => c.volume);
  const today = volumes[volumes.length - 1];
  const avg20 = average(volumes.slice(-21, -1));
  const std20 = stddev(volumes.slice(-21, -1));
  const zscore = (today - avg20) / std20;

  const signal = zscore > 2 ? "above_average" : zscore < -1 ? "below_average" : "normal";
  return { today, avg20, signal, zscore };
}
```

## 8. Easy-mode helpers (extend `src/simple.ts`)

```typescript
export const easyMode = {
  quickQuote: async (symbol: string) => {
    const [pb] = await vnstock.stock.trading.priceBoard([symbol]);
    return { symbol, price: pb.price, change: pb.percentPriceChange, volume: pb.totalVolume };
  },

  recentHistory: async (symbol: string, days: number = 30) => {
    return vnstock.stock.quote.history({
      symbols: [symbol],
      start: daysAgo(days + 10),
      timeFrame: "1D",
    }).then(arr => arr.slice(-days));
  },

  compareSymbols: async (symbols: string[]) => {
    const pbs = await vnstock.stock.trading.priceBoard(symbols);
    return pbs.map(pb => ({
      symbol: pb.symbol,
      price: pb.price,
      change: pb.percentPriceChange,
      volume: pb.totalVolume,
    }));
  },

  topMovers: async () => {
    const [gainers, losers] = await Promise.all([
      vnstock.stock.trading.topGainers(),
      vnstock.stock.trading.topLosers(),
    ]);
    return { gainers, losers };
  },
};
```

## 10. Response format conventions (MCP)

Mỗi MCP handler return:
```typescript
{
  content: [
    { type: "text", text: "<readable summary vi/en>" },
    { type: "text", text: JSON.stringify(structuredData, null, 2) }
  ],
  isError?: boolean,
}
```

Reason: Claude đọc text summary để relay user, dùng JSON cho reasoning/calculation. Dual response = best of both.

Error case:
```typescript
{
  content: [{
    type: "text",
    text: `Không tìm thấy mã "${symbol}". Hãy thử tool search_symbols với tên công ty.`,
  }],
  isError: true,
}
```

## 11. Optimizations

### (a) Session cache

```typescript
const quoteCache = new Map<string, { data, t: number }>();
const aiContextCache = new Map<string, { data, t: number }>();

const QUOTE_TTL = 30_000;
const AI_CONTEXT_TTL = 60_000;
```

Claude có thể gọi `get_quote("VCB")` rồi `get_ai_context("VCB")` rồi `to_ai_prompt("VCB")` trong 1 turn — cache giảm 2/3 VCI calls.

### (b) Lazy init

`await init()` chỉ trong handlers cần symbols/calendar (`search_symbols`, `list_symbols`, `is_trade_day`, `get_trading_calendar`, `get_company_info`).

`get_quote`/`get_history`/`top_movers`/AI tools skip → startup <500ms.

### (c) Parallel bulk

`compare_symbols`, `top_movers`, AI context (fetch candles + compute indicators song song).

### (d) Indicators pure functions

Không phụ thuộc network. Compute synchronous trong-process. AI context = `await fetchCandles` rồi sync compute.

## 16. Risks

| # | Risk | Mitigation |
|---|---|---|
| R1 | Scope creep (5 major capabilities trong 1 release) | Strict in/out scope, defer Cup&Handle/Triangle/Analog. Mỗi capability < 3 ngày dev. |
| R2 | Indicators bug (off-by-one, period edge) | Golden tests vs ta-lib reference values |
| R3 | AI context false signal (trend mis-classify) | Document confidence score, "neutral" default safe. Test với 20+ real symbols. |
| R4 | MCP protocol breaking change | Pin `@modelcontextprotocol/sdk` version |
| R5 | Claude spam → VCI 429 / Cloudflare 1015 | Session cache + issue [#10](https://github.com/ttqteo/vnstock-js/issues/10) Cloudflare detect |
| R6 | Watchlist file corruption | JSON validate on read, backup on write, atomic rename |
| R7 | Browser users hit "Node fs not available" error | Storage = no-op + warn, user inject adapter |
