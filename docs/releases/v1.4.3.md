# Phiên bản v1.4.3

Patch thuần additive, không breaking. Bổ sung giá trị giao dịch theo bar và mở khóa batch nhiều mã cho `quote.history()`.

v1.4.3 bổ sung:
- `QuoteHistory.value` — giá trị giao dịch (turnover) mỗi bar, đơn vị triệu VND
- `QuoteHistory.symbol` — mã CK theo bar, giúp `history()` batch nhiều mã trong 1 request

---

## New

### value — giá trị giao dịch mỗi bar

Endpoint chart VCI vốn trả `accumulatedValue` song song với OHLCV nhưng trước đây bị bỏ qua. Nay ánh xạ thành `QuoteHistory.value`.

```ts
const rows = await vnstock.stock.quote.history({
  symbols: ['VCI'],
  start: '2025-01-01',
  timeFrame: '1D',
});
// rows[0] = { symbol, date, open, high, low, close, volume, value }
```

**Đơn vị: TRIỆU VND** — giữ nguyên giá trị raw từ VCI, không scale như giá (`open/high/low/close` chia 1000 thành nghìn VND). Khi VCI không trả field, `value` là `undefined`.

Tự động xuất hiện ở mọi đường ra dùng chung `QuoteHistory`: SDK, MCP `get_history`, CLI `history --json` / `--csv`.

---

### symbol — history batch nhiều mã 1 request

Endpoint chart VCI nhận mảng `symbols` và trả kết quả từng mã trong **1 request**, nhưng trước đây transform vứt mất `symbol` nên mảng trả về không phân biệt được dòng nào của mã nào → batch vô dụng. Nay mỗi bar mang theo `symbol`.

```ts
const rows = await vnstock.stock.quote.history({
  symbols: ['VCI', 'FPT', 'HPG'],   // 1 HTTP request thay vì 3
  start: '2025-01-01',
  timeFrame: '1D',
});

const bySymbol = rows.reduce((m, r) => {
  (m[r.symbol!] ??= []).push(r);
  return m;
}, {} as Record<string, typeof rows>);
```

Gọi 1 mã/request cho cả danh sách là nguyên nhân chính bị Cloudflare chặn (429); batch về 1 request giảm tải đáng kể. Khuyến nghị batch ở mức hợp lý (vài chục mã/call) — payload quá lớn dễ chạm timeout 15s.

## Migration

Không breaking. `value` và `symbol` đều optional; code cũ chỉ đọc OHLCV vẫn chạy như trước.

- Nếu trước đây tự gọi `history()` từng mã trong vòng lặp để vẽ/so sánh, nay gộp `symbols: [...]` rồi nhóm theo `symbol`.
